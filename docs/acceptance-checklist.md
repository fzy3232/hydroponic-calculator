# 首版验收清单

> 自动化能验的部分**已经跑过**（见文末「已自动验证」）；
> 下面这些是 **GUI 交互**，脚本无法代劳，请手工过一遍。

---

## 一、必须过（做不到就是功能缺失）

### 1. 导出 CSV 是否真实落盘 ★最高优先

**为什么列第一**：Tauri（WebView2）里 Blob 下载不可靠，导出改用了系统「另存为」对话框。
这一步是本项目唯一改动的业务逻辑，**没验证就等于没做**。

1. 打开应用 → 底部「⑥ 数据管理」
2. 点「导出肥料CSV」
3. **期望**：弹出 Windows「另存为」对话框 → 选一个桌面路径 → 保存
4. **期望**：界面上出现绿字「✓ 已保存到：<你选的路径>」
5. 用 Excel 打开该文件
6. **期望**：中文不乱码（`toCSV` 带 UTF-8 BOM）

同样步骤测「导出作物CSV」「导出术语CSV」。

### 2. 导入 CSV 是否可用

1. 把桌面上的 `fertilizers.csv` 改一行（比如把某个肥料名加个后缀）保存
2. 点「导入肥料CSV」→ 选该文件
3. **期望**：弹出提示「已导入 35 种肥料」，页面列表出现改动
4. **再测 GBK 编码**：用记事本打开该 CSV → 另存为 → 编码选「ANSI」→ 覆盖原文件
5. 重新导入
6. **期望**：中文仍不乱码（代码里有 GBK 回退解码）

### 3. 导出 Excel ★（替代原来的打印）

**为什么列前面**：这是最常用的输出方式——Excel 既能直接打印，数字还能在表里继续算。

1. 点「⑤ 开始计算」出结果
2. 点旁边的「**导出 Excel**」
3. **期望**：弹出「另存为」对话框 → 选桌面 → 保存
4. **期望**：界面提示「✓ 已保存到：<路径>」
5. 用 Excel / WPS 打开该文件
6. **期望**：有 **4 张工作表**：配方信息 / 原料用量 / 目标达成 / 形态核对
7. **期望**：中文不乱码；化学式带下标（如 `Ca(NO₃)₂·4H₂O`）
8. **期望**：**数字能参与计算** —— 选中「用量（g）」一列，Excel 状态栏应显示求和结果；
   如果显示的是"计数"而不是"求和"，说明被当成了文本（请告诉我）

### 3b. 打印（备用路径）

「打印」按钮走 `window.print()`。若点它**没有反应**也不影响使用——
从导出的 Excel 里打印更可靠。这条只作为兜底确认。

### 4. 中文输入法

**背景**：WebView2 有已知的 CJK 输入法缺陷（WebView2Feedback#5625 / tauri#15436），
但本项目**主流程 ①→⑤ 全是下拉框/数字框/复选框，不需要输入中文**——
只有 ⑥ 数据管理里编辑肥料名、作物名、备注时才涉及。

1. 打开「编辑肥料库」
2. 找一个「名称」输入框（**框里已有内容**，这一点很重要，issue 多发生在非空框内）
3. 用微软拼音连续输入 5–10 个汉字，并做候选翻页、退格改写
4. **期望**：不卡死、不丢字、标点不重复
5. 同样测「编辑作物库」的「作物」「备注」列

> 若这里卡死：不必放弃 Tauri，可以把中文列的编辑改成"弹窗单行输入"规避
> （成本需评估）。

## 二、应该过（体验完整性）

### 5. 数据持久化跨重启

1. 在 ⑥ 里改一个肥料名 → 保存改动
2. **完全关闭应用**（窗口 × 或任务栏关闭）
3. 重新打开
4. **期望**：改动还在

> 数据存在 WebView2 的用户数据目录，位置由 `identifier`（`com.hydroponic.calculator`）决定。
> **注意**：这个 identifier 发布后不能再改，否则用户数据会"看似丢失"。

### 6. 便携性验证（这是你选 Tauri 的初衷）

1. 把 `水培营养液配方计算器-便携版.exe` 复制到 **U 盘**
2. 在另一台装了 WebView2 的电脑上双击
3. **期望**：直接运行，无需安装

> ⚠️ **要知道的一点**：便携版**不会**带走你的肥料库/作物库改动——
> 数据存在系统里的 WebView2 用户目录，不跟着 exe 走。
> 换电脑请用「导出 CSV」再在新机器上「导入 CSV」。

### 7. 核心流程回归

- [ ] **顶栏冻结**：把内容区滚到底，「水培营养液配方计算器」标题栏与左侧菜单**保持原位不动**
- [ ] **左侧菜单切换**：点「数据编辑」→ 内容区换成数据编辑；点「化学计算」→ 换回来；当前项高亮
- [ ] 切换视图后，内容区**回到顶部**（不会停在上一屏的半截位置）
- [ ] 切换作物 → 目标浓度**自动**载入（不用点按钮）
- [ ] 切换生育期 → 同样自动载入
- [ ] 点「智能推荐」→ 自动勾选一套原料
- [ ] 点「开始计算」→ 出现用量表 / 达成情况 / 形态核对
- [ ] 达成度表**默认收起**，点标题可展开
- [ ] 「📖 术语词典」按钮**有可见边框**，点开能搜到术语，每条有「对种植的影响」
- [ ] 鼠标停在 ② 的元素名上 → 悬浮提示**同时有「含义」和「对种植的影响」**
- [ ] 用量表数值列**右对齐**，无 `-0.0%`，无显示为 0 的行
- [ ] 微量原料下有绿框「微量原料称量建议」
